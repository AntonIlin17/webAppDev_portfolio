# Design variants

Twenty alternative home-page directions for the portfolio, authored as self-contained
HTML artboards for the "Portfolio Design Variants" canvas
(https://claude.ai/artifact/8DVgNmuFobBmouHjGwFu8o).

Each `*.dc.html` file is one variant: nav, hero, selected work, services, footer, plus a
grey spec strip (palette, fonts, signature move). All use the real site copy so only the
design changes. `canvas.json` is the canvas layout index.

Open any file directly in a browser to preview it; the `<x-dc>` / `<helmet>` wrappers are
inert outside the canvas. Once a direction is chosen, port its tokens and components into
`src/index.css` and `src/App.css`.
