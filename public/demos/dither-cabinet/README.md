# Dither Cabinet browser demo

Anton Ilin’s interactive collection of 58 sculptural studies rendered with WebGL2 and a Canvas fallback. The single HTML file includes the graphics code and bundled study artwork. Open `index.html` in a browser or try the [portfolio demo](https://web-app-dev-portfolio.vercel.app/demos/dither-cabinet/index.html).

Explore the collection, switch rendering modes, and adjust the surface, lighting, ink, and motion. This build uses the bundled studies. The full workspace also has a local Photo Lab that requires separate model files.
